## 🎮 Project Overview
**RedPal** is an engaging 2D iOS arcade and action game built natively with **Swift**, **SwiftUI**, and **SpriteKit**. 

The player controls and interacts with **Tomy**, a courageous little tomato warrior, navigating diverse game modes that combine high-reflex slicing mechanics, boss combat encounters, interactive mini-games, and relaxing playground scenes.

The application was designed, prototyped, and engineered in an agile team environment following Apple's Human Interface Guidelines (HIG) and object-oriented iOS architecture.

---

## ✨ Key Features & Gameplay Modes

- ⚔️ **Slicer Arcade Mode (`SlicerGameScene`):** Fast-paced touch gesture slicing mechanics with physics collision detection, particle effects, and dynamic score multipliers.
- 👹 **Boss Battle Arena (`BossScene` & `BossBattleView`):** Real-time boss combat system with state-based enemy behaviors, health bars, attack telegraphing, and victory/defeat sequences.
- 🎯 **Training Ground (`TrainingScene`):** Practice modes to master touch gestures, combo timing, and mechanics.
- ☕ **Relax & Playground Scene (`RelaxScene`):** Casual interactive interface showcasing fluid animations and ambient interaction.
- 🎨 **Retro Pixel-Art Aesthetic:** Custom visual identity, sprite sheets, sound effects, and custom typography (`PressStart2P`).

## 🛠️ Tech Stack & Architecture

- **Language:** Swift 5+
- **UI Framework:** SwiftUI & UIKit
- **Game Engine:** SpriteKit (Physics, Particle Emitters, PhysicsBodies, Nodes, Actions)
- **Design Pattern:** MVVM / Scene-State Management
- **IDE & Tooling:** Xcode, Git, Swift Playgrounds

## 🚀 How to Run the Project (macOS / Xcode)

1. Clone this repository:
   ```bash
   git clone https://github.com/PaoloDes04/RedPal.git
   ```
2. Open the Xcode project:
   ```bash
   open RedPal.xcodeproj
   ```
3. Select an iOS Simulator (e.g. iPhone 15 / iPhone 16) or a connected physical iOS device.
4. Press **Cmd + R** to build and run.
